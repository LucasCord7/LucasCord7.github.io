OCR / VISION Do documento à informação

OCR AI Vision

Da imagem digitalizada ao documento pesquisável, com integração ao sistema registral.

  1. Documento
  2. Extração
  3. Conferência
  4. Exportação
O desafio
Transformar matrículas e registros auxiliares digitalizados em conteúdo utilizável, preservando o texto original, as referências entre atos e a identificação de cada documento.
O que desenvolvi
Aplicação desktop migrada de Python para Go com Wails e interface Vue 3. Combina modelos de visão e linguagem para extração com Tesseract para produzir PDFs que mantêm a imagem original e permitem pesquisar e copiar o texto.

Gera texto formatado em RTF, integra a gravação ao SQL Server e registra a origem do processamento em logs por arquivo. Inclui identificação do tipo documental, conferência manual e verificação de duplicidades antes da gravação.

  • Go
  • Wails
  • Vue 3
  • Tesseract
  • SQL Server
Conhecer os recursos

Processamento documental: suporte a TIFF multipágina, identificação de matrículas e registros auxiliares e tratamento conservador do texto em português, priorizando a fidelidade ao documento.

Integração e rastreabilidade: exportação em PDF e RTF, persistência em SQL Server e logs com informações do arquivo, modelo e provedor utilizados.

Aplicação desktop: mantém o progresso ao navegar entre abas, permite configurar diferentes provedores de IA e armazena chaves no gerenciador de credenciais do Windows.

02 / IA e documentosAplicação web
RAG / CONTEXTO Documentos conectados ao contexto

cartorio-ia

Um assistente jurídico que conecta perguntas ao conteúdo dos documentos.

  1. Documentos
  2. Indexação
  3. Busca
  4. Contexto
O desafio
Localizar informações relevantes em acervos jurídicos, inclusive em documentos digitalizados, e reunir o contexto necessário para apoiar a análise.
O que desenvolvi
Aplicação com backend em FastAPI e interface Vue 3 para ingestão, recuperação e análise de documentos. O OCR extrai o texto, enquanto PostgreSQL e pgvector sustentam a busca textual e por similaridade semântica.

A arquitetura RAG recupera trechos relevantes para contextualizar as respostas dos modelos de linguagem. A integração com múltiplos provedores inclui alternativas de processamento por fallback.

  • Python
  • FastAPI
  • Vue 3
  • PostgreSQL
  • pgvector
Entender a solução

Os documentos passam por ingestão e extração de texto. A busca combina correspondência textual com similaridade semântica para recuperar trechos relacionados à consulta.

Esses trechos fornecem contexto ao modelo de linguagem. A arquitetura integra diferentes provedores para permitir alternativas no processamento.

Tradutor de Quadrinhos

Ferramenta para traduzir mangás e quadrinhos, reunindo detecção de texto, OCR, tradução por modelos de linguagem e edição visual. Permite abrir imagens e arquivos CBZ/ZIP, traduzir os balões e ajustar o resultado manualmente.

Conhecer os recursos

Integra provedores como Gemini, OpenAI, Anthropic, Groq e DeepSeek. O reconhecimento de negrito e itálico e o uso das fontes instaladas ajudam a recompor o texto traduzido.

A limpeza dos balões usa técnicas de reconstrução de imagem com LaMA e AOT-GAN. O editor permite criar, redimensionar e ajustar caixas de texto, combinando automação com revisão manual.

Desenvolvimento, adaptações e identidade visual por Lucas Cordeiro. Projeto de origem: ComicTranslate, de ogkalu2 / ComicLabs.

  • Python
  • OCR
  • LLMs
  • Inpainting

04

Painel de Produtividade — Workflow

Dashboard de gestão para acompanhar a operação de cartórios em cinco dimensões: volume, prazo, qualidade, certidões e financeiro. Transforma dados do SQL Server em indicadores de produção, pendências, atrasos e erros, com análise por período, etapa e colaborador.

Entender a solução

Do indicador ao detalhe: os cards e gráficos permitem consultar os registros que compõem cada resultado. A navegação combina tabelas filtradas, painéis de detalhamento, busca, paginação e exportação para Excel.

Arquitetura local e nuvem: um agente instalado na unidade consulta o SQL Server e se comunica com a API FastAPI por WebSocket. Consultas históricas são executadas sob demanda pelo agente, sem acesso direto da nuvem ao banco local.

Atualização eficiente: utiliza envio incremental de alterações, compressão e cache persistente em PostgreSQL. A distribuição de dados é delimitada por unidade, com acesso por token de visualização.

Leitura operacional: reúne acompanhamento de protocolos, etapas em atraso, pausas, erros de tramitação, emissão de certidões e indicadores financeiros em uma interface Vue 3 com gráficos interativos.

  • Python / FastAPI
  • SQL Server
  • PostgreSQL
  • Vue 3 / Pinia
  • ApexCharts
  • WebSockets

05

Painel de Monitoramento de Cartórios

Plataforma de monitoramento distribuído para acompanhar a disponibilidade dos servidores, bancos de dados e serviços que sustentam a operação de múltiplos cartórios. Centraliza o estado das unidades em um mapa e em painéis, com alertas visuais e sonoros para apoiar a identificação de falhas.

Entender a solução

Coleta nas unidades: um agente Windows verifica o SQL Server, serviços operacionais e recursos do servidor, como CPU e disco. Envia o estado à central para acompanhamento pelo navegador.

Visibilidade em tempo real: a API FastAPI distribui atualizações por WebSocket à interface Vue 3. O mapa em Leaflet organiza a visão geográfica, enquanto gráficos e histórico de eventos apoiam a análise de disponibilidade.

Detecção de indisponibilidade: além dos estados reportados pelo agente, uma rotina central identifica unidades que deixam de se comunicar e atualiza os alertas do painel.

Eficiência de comunicação: combina sinais leves de atividade, envio de mudanças de estado, compressão e modo econômico noturno. O PostgreSQL mantém o histórico das alterações para consulta posterior.

  • Python / FastAPI
  • Windows Services
  • PostgreSQL
  • Vue 3 / Pinia
  • Leaflet
  • WebSockets
