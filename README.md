## Abrir localmente

Abra `index.html` em um navegador ou sirva a pasta com qualquer servidor estático.

## Publicar no GitHub Pages

O repositório deve se chamar `LucasCord7.github.io` para publicar o portfólio em
`https://lucascord7.github.io/`. O site usa arquivos estáticos na raiz, sem etapa de build.

1. Envie os arquivos desta pasta para a branch `main` do repositório público `LucasCord7.github.io`.
2. Em **Settings → Pages**, escolha **Deploy from a branch**.
3. Selecione `main` e a pasta `/ (root)` e salve.
4. Confirme a publicação em `https://lucascord7.github.io/`.
